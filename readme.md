# Student Task Manager

## Project Description

Student Task Manager is a simple web application developed as a collaborative Git and GitHub project.

The application allows students to:

- Add tasks
- View tasks
- Search tasks
- Mark tasks as completed
- Delete tasks

## Git Workflow

The project follows a collaborative Git workflow:

1. Create project
2. Initialize Git
3. Create commits
4. Create GitHub repository
5. Create feature branches
6. Develop features
7. Push branches
8. Create issues
9. Create pull requests
10. Perform code reviews
11. Merge branches
12. Resolve merge conflicts
13. Demonstrate Git recovery commands
14. Create tag and release
